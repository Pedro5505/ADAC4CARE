# API contract

The live OpenAPI schema is generated by `drf-spectacular` at `/api/schema/`, with interactive documentation at `/api/docs/`.

## Primary resources

- `GET /api/homes/` — authorised SIL homes.
- `GET|POST /api/clients/` — client profiles scoped to the authenticated organisation.
- `GET|POST /api/medication-orders/` — medication charts and orders with explicit eight-right fields.
- `GET|POST /api/administrations/` — immutable administration outcomes; updates and deletes are unavailable.
- `GET|POST /api/messages/` — pharmacy, prescriber, and care-team messages tied to a client and optional order.

All routes require authentication in production. Collection and object access must remain organisation-scoped. External integrations should use versioned endpoints, idempotency keys for writes, and a separately provisioned service identity.
